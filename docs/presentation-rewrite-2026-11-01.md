# 赛事展示重写 · 2026-11-01

按本轮要求重写规则、赛程和海选展示，并同步首页摘要及比赛室阶段标题。展示以赛事公开规则和实际运行数据为依据，不修改已发布配置、选手成绩或既有晋级结果。

## 展示语义

| 赛制 | 规则与赛程的实际展示 |
| --- | --- |
| 成绩排名 / 海选 | 完整已审成绩、取分方式、比较方向、课题谱面与难度、正式或暂列名次、实际晋级去向。不再将排名阶段当作对战阶段显示胜负 0。独立排名赛与前置海选区分最终名次和晋级状态。 |
| 单败 | 一败淘汰、轮空、阶段晋级目标与对局曲序；使用“单败对阵”和轮次，不借用双败胜败者组说明。 |
| 双败 | 胜者组、败者组、总决赛、重置决赛分区显示。按该阶段实际生效规则分别解释 reset、一曲胜优势及单场总决赛变体；不再把全局默认决赛策略误用于独立阶段。 |
| 单循环 | 每对交手一次、奇数轮休、胜场和负场排序及并列判定。没有虚构积分制、淘汰组或重置决赛。 |

排名阶段按后端实际使用的赛事级指标展示；对战阶段使用自己的 StagePlan 覆盖计分、选禁、曲序和同分规则。首页摘要同步按阶段生成，不再用一套默认对局 BP 和总分概括所有阶段。

海选正式名次优先使用阶段封榜后的 placements，晋级标记使用下一阶段 participants；比分相同但已完成附加赛排序的情况不会再按原始分数猜测晋级者。未封榜只显示“暂列”，未完成成绩不冒充有效总分。

## 折叠与布局

赛程每个阶段均有展开 / 收起按钮。已结束与未开始阶段默认收起，进行中及待判定阶段默认展开；用户手动选择不会被轮询刷新覆盖。分轮和列表两种视图都保留，双败不再把所有组混排在一条横向时间线上。总决赛和重置决赛不显示内部的特殊轮次编号。

表格只在自身容器横向滚动；页面正文仍独立纵向滚动。新界面继续使用主题和字号变量。浏览器检查 1280px 桌面与默认 499px 窄屏，document.scrollWidth 均未超过可视宽度；临时尺寸已恢复。

## 发现并修复的计算问题

新增回归复现了原名次算法的问题：同轮淘汰者会因获得轮空、实际胜场不同而被拆成不同名次。原测试在 5 人单败即失败。修复移除了淘汰赛名次键中不应存在的额外胜场比较，单败和双败都按实际淘汰位置保留并列，循环赛仍按其胜负规则排序。

该修正影响后续计算，不自动重算或覆盖历史封榜记录。当前 16 人演示赛的赛事、报名、对局、阶段结果、海选快照五张关键表在服务重启前后内容摘要一致。
