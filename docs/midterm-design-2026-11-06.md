# 期中前端改版 · 2026-11-06

本次在 HW2 现有 Scala + React 前后端上完成界面改版，覆盖日常使用和录制演示的 11 个核心入口。业务仍为单赛事模板，保留原 API、身份校验、审核、计分、晋级及已发布规则冻结机制。没有修改 Scala、数据库迁移或正式赛事数据。

## 页面设计

| 页面 | 本轮布局与要素 |
| --- | --- |
| 赛事总览 `/` | 赛事主视觉、状态与当前阶段、四项数据概览、进行中的比赛/已确认赛果、阶段进程、参赛入口与资料侧栏。结束后可展示已确认冠军。 |
| 赛事规则 `/rules` | 独立页头与规则版本、项目概览、可跳转的阶段目录、各阶段规则、审核与异常说明。 |
| 参赛者 `/participants` | 报名统计、状态筛选与昵称搜索、种子编号、选手身份卡、无匹配结果反馈。 |
| 赛事图池 `/pool` | 图池概览、子池筛选、曲名/作者/难度搜索、曲目与谱面信息表、分页与导出。 |
| 海选 `/qualifier` | 封榜状态、课题卡、成绩与名额概览、正式/暂列排行榜、实际资格状态、交分与个人尝试。 |
| 赛程 `/schedule` | 阶段与比赛统计、对阵/列表切换、阶段折叠、排名去向、带种子与胜者标记的比赛入口。 |
| 比赛室 `/matches/:matchId` | 双方对阵区、流程进度、已审比分、选禁时间线、实际演奏顺序，以及按身份显示的交分和裁判操作区。 |
| 登录 `/auth` | 桌面双栏入口、登录/注册切换、密码显隐、表单反馈；手机优先显示账号表单。 |
| 参赛中心 `/me` | 身份及提交概览、本场资格、提交记录与比赛直达、账户侧栏；未登录和暂无记录均有独立状态。 |
| 赛务后台 `/manage` | 赛事工作台、待审事项与比赛统计、分类审核区、开赛确认、操作记录及既有裁判/申诉模块。 |
| 赛事配置 `/manage/config` | 分步导航、表单与配置预览、草稿保存。已发布时改用独立的冻结配置总览，展示阶段、版本、导出与赛务入口。 |

全站统一使用清晰的页头、面板、状态徽章和表格。保留日间、夜间、跟随系统以及大字号模式；手机导航使用抽屉，支持关闭按钮、遮罩及 Escape，导航滚动时固定保留律竞标识。宽表格和对阵列在自己的容器内横向滚动。

## 实现与课程复核

- 页面业务区域和协调逻辑保留在所属页面；总览、图池、海选和参赛中心拆分为明确的组件、hooks 和对象。复杂入口展示业务骨架，分别对应规范 39–47。
- 原有具体 API 类、共享传输、会话和服务边界保持不变，未增加绕过后端权限的调用方式。
- 样式采用 Tailwind。`styles.css` 中新增部分为语义主题变量和使用 Tailwind `@apply` 的文档级默认样式；页面布局在组件中。运行时主题色仅通过 CSS 变量传入，保留可配置赛事主视觉。
- 删除原 `index.html` 根元素上约 46 KB 的全局后代样式堆叠，避免它覆盖各页面自身的文字、链接、表单和布局。
- 页面提供加载、错误、空内容及操作状态。排名仍按实际封榜/晋级记录显示，不因名次落在前 N 而假定已经晋级。
- 路由按需加载，保留生产构建的 API 类名。最终主入口 JavaScript 约 343 KB，未产生原来的单包大小警告。
