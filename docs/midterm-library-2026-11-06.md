## 本次变化

- 修复赛事定义的完整模板导入、数字输入、阶段继承、独立阶段规则、保存状态、版本冲突与校验导航。公开选禁方式和同分比较链为赛事级设置，独立阶段只覆盖后端实际支持的字段。
- 曲库独立保存元数据，图池独立保存比赛所用谱面、子池和用途。曲库导入、更新、替换不自动修改比赛图池与已发布快照。
- 导入支持 JSON 数组及 charts / rows / data / songs / music 包装、CSV / TSV、UTF-8 BOM、引号和换行、常见中英文列名、数字来源标识、maimai / maimai-dx 别名。最简行只需曲名与难度；其余基本字段有默认值。正式数据建议保留来源稳定标识。同名不同谱面不按曲名合并。
- 缺少曲师、游戏版本或定数的合并导入保留已有值；替换模式明确作用于当前游戏。未知定数为 null，不用显示等级的加号推算定数。
- 图池工作台支持卡片多选、全选本页 / 筛选结果、拖放到子池、批量分配、移出、谱面用途更新、多子池重叠、难度与定数范围筛选。曲库和图池均支持搜索、排序、分页。
- 图池保存使用赛事版本号；过期请求不能覆盖新配置。离开未保存的分池页面可继续编辑、放弃或保存后跳转。已发布赛事拒绝修改分池。
- 曲库每款游戏与赛事图池分别上限 10000 张；导入文件上限 12 MiB，API 总请求上限 16 MiB。证据附件仍使用原有独立限制。
- 配置导航换行，列表分页，无 range 滑条或可见滚动条；页面仍可正常滚轮和触控滚动。后台管理入口置于导航上方。手机使用紧凑游戏选择与子池布局。
- 新界面使用唱片、轨道与几何层叠图形，保留深浅色和大字号。新增页面不放说明段落。未调用图片或 3D 生成服务（0 / 10）。

## 后端与课程结构复核

`events` 域拥有 chart_library 表及逐表初始化，v5 迁移只从已有图池补充元数据，不修改已有图池。每个新操作有独立 Message、同一连接上的 IO 计划、路由认证及前端 API 类。分池用途与导入模式使用封闭类型。SQL 留在表模块，纯映射位于服务私有工具，前端状态不可变；两页分别拥有入口、hooks、objects 和 components，共用的元数据计算位于 domain。样式使用 Tailwind。

新增五个对外接口：GET /library、PUT /library、PUT /events/:id/pool、GET /chart-presets、GET /chart-presets/:game；均保留统一派生的 RPC 入口。曲库与预设仅主办可读写。图池写入仍经过赛事归属、版本、草稿状态和完整输入检查。替换曲库后，已选比赛谱面的快照仍可继续编辑。
