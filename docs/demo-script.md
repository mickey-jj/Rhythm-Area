> 当前 16 人演示赛请使用 [175 秒录制脚本](demo16-recording-script.md)。下方提纲及视频说明保留为历史材料。

由学生本人录制真实使用流程，≤180 秒。自动化验收视频已制作，但它与课程要求的学生本人亲录分开。

开头说明：交付物是一套可配置单赛事网站模板，一份部署只承载一场比赛；范式配置是示例。

| 时间 | 展示 |
| --- | --- |
| 0–20 秒 | 根目录 Start.cmd 启动；首次准备页与主办初始化 |
| 20–55 秒 | /manage/config 内选择示例或导入配置，修改名称/外观/指标，展示 BP 与独立曲序 |
| 55–75 秒 | 校验、模拟、发布；首页直接进入这场赛事，没有多赛事大厅 |
| 75–100 秒 | 注册、报名与主办审核；明确账号属于当前赛事部署 |
| 100–125 秒 | 准备好的一场比赛完成 BP，展示持久化曲序 |
| 125–155 秒 | 选手交完整尝试、主办审核、同分加赛或真实晋级 |
| 155–175 秒 | 归档保留结果；导出白名单配置，说明新部署复用不带人员与成绩 |

为避免等待，可提前准备不同阶段的隔离演示实例，而不是在同一个网站新增一批公开赛事卡。所有虚构成绩明确标记演示，不冒充真实官方比赛。

录制时不展示真实密码、数据库文件或私人证据。源码包根目录要包含 Start.cmd、Stop.cmd、instance.config.json 和启动说明，排除 .local、依赖与缓存；源码加视频合计按低于 100,000,000 字节留余量。

## 本轮录制文件（2026-10-30）

- deliverables/hw2-demo.mp4：约 149 秒，82 张来自真实浏览器的操作状态采样帧，缩短操作间等待，无音轨。
- deliverables/hw2-verification-full.mp4：按采集时间保留约 9 分 26 秒的过程，无音轨。

实际演示：空白模板 → 建立虚构主办 → 导入个人单败预设与说明 → 图池预检 → 容量设为 2 → 保存、校验、发布 → 两位虚构选手分别注册报名 → 主办审核 → 冻结生成唯一决赛 → 主办有记录代操作完成 BP → 两位选手分别交完整尝试 → 主办审核 → 按精确总分确认冠军 → 日夜切换。

桌面窗口录制授权接口超时，因此采用已授权浏览器截图接口在操作与状态更新处采集，再用 FFmpeg 编码。该文件是网页状态采样录像，不是高帧率桌面连续录屏；保留真实页面与实际持久化结果，没有模拟赛果。编码参考 [FFmpeg 官方文档](https://ffmpeg.org/ffmpeg.html)。

学生提交前请按上方提纲亲自操作并录制，时长仍须不超过 180 秒，不应把本自动化录像表述成本人录制。
